[P0-4] Doble fuente de verdad en el código generado + sin escape de HTML
  Archivo: src/components/Salida.jsx
  Problema a: el string HTML+CSS se construye a mano con template literal
              duplicando los estilos reales del preview → si cambia un estilo
              y se olvida actualizar la plantilla, preview y salida divergen.
  Problema b: se copia leyendo `document.getElementById('codigo').textContent`
              (DOM como fuente de verdad) en vez de generar el string desde el
              estado.
  Problema c: el texto del usuario se inyecta SIN escapar. Un texto con `<`,
              `>` o `&` rompe (o inyecta marcado en) el snippet copiado.
  Acción:   crear src/lib/generateCode.js con una única función
            `generateCode(texto, estilos) -> string`, que:
              - derive el CSS de las MISMAS variables que usa el preview,
              - escapen `& < > " '` en el texto,
              - sea usada TANTO para el <pre> como para clipboard.writeText.
  Criterio: escribir `<script>alert(1)</script>` en el preview genera snippet
            escapado; no existe ningún valor de estilo duplicado en plantilla.

[x] P0-5 Timer sin limpieza (setState tras unmount)  ✔ RESUELTO 2026-10-28
